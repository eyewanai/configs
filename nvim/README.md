# Neovim

Конфигурация рассчитана на Neovim 0.12+ и использует `lazy.nvim`.

## Зависимости

Обязательные:

- `nvim` 0.12 или новее;
- `git` — для установки `lazy.nvim` и плагинов;
- C-компилятор — для Treesitter-парсеров;
- `rg` — для поиска через Telescope;
- `go` и `gopls` — для подсветки ошибок и переходов в Go-файлах.

Дополнительные:

- `lazygit` — открывается по `Space g g`;
- Nerd Font в терминале — для иконок файлового дерева.

На macOS зависимости можно установить так:

```sh
brew install neovim ripgrep lazygit
go install golang.org/x/tools/gopls@latest
```

На Linux названия пакетов зависят от дистрибутива. `gopls` можно установить
через Go-команду выше.

## Установка на новую машину

Склонировать репозиторий и выполнить из его корня:

```sh
./nvim/install.sh
```

Скрипт:

1. создаёт `~/.config`, если его ещё нет;
2. сохраняет существующий `~/.config/nvim` в каталог с timestamp;
3. создаёт симлинк на этот каталог `nvim`;
4. устанавливает плагины из `lazy-lock.json`.

После первого запуска Neovim конфигурация автоматически установит нужные
Treesitter-парсеры. Если какой-то внешний инструмент отсутствует, Neovim
запустится, но соответствующая функция будет недоступна.

## Что не нужно переносить

Не коммитятся и не требуются для восстановления конфигурации:

- `~/.local/share/nvim/lazy` — установленные плагины;
- `~/.local/share/nvim/site/parser` — скомпилированные Treesitter-парсеры;
- `~/.local/state/nvim` — логи, swap-файлы, история и shada;
- `~/.cache/nvim` — кэш Lua.

`lazy-lock.json` фиксирует версии плагинов, поэтому чистая установка
восстановит тот же набор версий.
